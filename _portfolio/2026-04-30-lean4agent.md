## Overview

Lean4Agent is a multi-agent system that generates Lean 4 code and formal proofs from natural-language mathematical problems. It was built during my research internship at IIT Delhi, where the aim was to explore whether LLM-driven agents could produce machine-checkable mathematical formalizations.

## What I built

- **Multi-agent pipeline:** separate agents handle problem parsing, proof sketching, Lean 4 code generation, and error-driven self-correction by reading the Lean 4 compiler's diagnostics.
- **Lean 4 codegen:** translates informal problem statements into Lean 4 `theorem`/`proof` statements using the mathlib4 library where applicable.
- **Feedback loop:** failed compilations are fed back to the agent as context so it can revise the proof until it type-checks.
- **Evaluation:** measured proof-success rate on a set of undergraduate-level mathematical problems.

## Outcome

The system could produce valid Lean 4 proofs for a subset of problems, demonstrating that agentic workflows with compiler-in-the-loop correction are a viable path toward automated formal verification — while also surfacing the gaps that keep fully automated theorem proving out of reach today.
