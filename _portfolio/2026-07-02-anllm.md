## Overview

AnLLM is a from-scratch LLM inference engine written on Apple's MLX framework. The goal was to understand how transformer inference actually runs end to end — tokenization, KV-cache attention, sampling, and batched generation — without leaning on Hugging Face or vLLM.

## What I built

- **Transformer forward pass:** attention, MLP, layer-norm, and embedding layers implemented directly in MLX.
- **KV-cache:** key/value caching for autoregressive generation so each step reuses prior computations.
- **Sampling:** greedy, top-k, top-p, and temperature sampling.
- **Batched generation:** prompt processing and token streaming on Apple Silicon (CPU/GPU via MLX).

## Outcome

The engine runs small LLMs end to end on Apple Silicon and matches reference implementations on greedy decoding. It served as a practical lab for learning how inference systems manage memory and compute under tight latency constraints.
