## Overview

MATRIX is a ground-up implementation of core linear algebra kernels in C: matrix multiplication, LU decomposition, and basic solvers. The goal was to understand how performance-critical numerical code works beneath NumPy and BLAS, and to see how far hand-tuned C can go.

## What I built

- **Kernels in C:** dense matrix multiplication, LU decomposition with partial pivoting, and forward/back substitution, all written from scratch without external linear-algebra libraries.
- **Performance engineering:** cache-blocking (tiling) for matrix multiplication, contiguous memory layouts, and minimal overhead in hot loops.
- **Parallelism:** OpenMP-based multi-threading for the larger kernels, with speedup measured on multi-core CPUs.
- **Validation:** results cross-checked against NumPy for correctness.

## Outcome

Blocked, multi-threaded C matched or exceeded naive implementations by a wide margin on large matrices, showing how data layout and cache awareness dominate linear-algebra performance. The project became a reference for later work building the Torchlight deep-learning framework.
